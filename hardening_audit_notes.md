# Hardening audit notes

Sources: live app https://sydneyautomationco-job-system.vercel.app/ ; repository https://github.com/buddduaviogt668/sydneyautomationco-job-system

As of 25 Aug 2026, the live browser data contained 99 jobs, 36 client records observed by aggregation, 20 supplier invoices, and 19 expenses. Corrected current exposure from prior live review: AJB Electrical $24,035.00 outstanding (deposit $14,420.99 plus balance $9,614.01); Matrix Electrical Group $3,886.00 overdue; Quest Apartments $797.50 overdue; Towns Security $770.00 overdue; Ivo Andrejco $715.00 overdue; Black Rock $1,100.00 current with seven-day terms from its 20 Aug issue date, due 27 Aug if that issue date is correct. Corrected overdue total is $6,168.50; approximate total outstanding is $31,303.50.

Architecture findings: the deployed root app is a single large client-side index.html with localStorage, optional File System Access backups, and Supabase REST sync. The repo also contains a nested master-system React/Vite template which appears separate from the deployed root app. The client bundle contains a Supabase URL, anon key, and x-app-secret header value; no visible login/authentication layer was found in the root app scan. AI API keys are stored in browser storage. Cloud sync has checksums and conflict checks but per-dataset writes are not one atomic transaction. Local file saves are async and non-blocking.

Code/data findings: invoice values historically mix GST-inclusive and GST-exclusive conventions; jobAmountDisplay contains hard-coded confirmed invoice exceptions and heuristics based on quote-versus-invoice differences. Debtor rows do not yet render separate deposit and balance invoices. Due dates are not consistently present; SAI_100108 had no due date in the live data. Existing comprehensive audit found legacy export issues: SAI_100060 line total $3,995 versus invoiceAmount balance $1,997.50; SAI_100059 line sum $8.40 versus invoiceAmount $558.40; KM trip hist_19 references unknown job SAI_100041. SAI_100062 was corrected live for Maggie Yiu: invoice number/date/due date/paid date cleared, amount remains $0.00, status set to lost, notes preserved. Regression script verify_ui_math.js originally used a hard-coded Windows data path; it was changed to accept a CLI path and default to the repo export. Quick capture for expenses/supplier invoices was pushed as commit 51d96b0. Earlier unpaid-deposit fix commits: 4090a89 and 241ea63.

Required production hardening: canonical invoice money fields (subtotal, GST, total inc GST, issue date, due date, status, paid date), separate deposit/balance invoice entities, customer-specific terms, debtor row reconciliation, append-only audit log, server-side authenticated database with role-based access, protected secrets, atomic transactions or versioned writes, reliable backups and restore tests, validation and undo for destructive actions, automated CI tests, and mobile/accessibility regression checks.
